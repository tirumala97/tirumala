21-Day Dialog Schedule Maker

This page uses dialog boxes to create a schedule for 21 days starting tomorrow. Each day must have tasks between 04:00 and 22:00. After data entry you'll get a summary and can export CSV or (optionally) create GitHub issues.

Option: Create GitHub Issues (one issue per task)

Enter target repo and a Personal Access Token with "repo" scope for private repos or "public_repo" for public repos. The token is sent directly from your browser to GitHub — do not share it.
